# 系统架构设计师 · 备考笔记

软考高级「系统架构设计师」学习笔记仓库，教材为《系统架构设计师教程》第二版。

由本人阅读实体书后手写笔记初稿，借助 AI 辅助核对、整理为精简笔记 + 记忆卡片，目标是搭建一套可持续复习的备考体系。

## 目录结构

```
notes/      各章节笔记初稿（手写，未经整理）
summaries/  整理后的小节 / 章节总结，含 SVG 示意图
review/     记忆卡片与复习策略
```
