## 知识结构

| 小节 | 核心内容 | 关键结论 |
| --- | --- | --- |
| 3.1 信息系统概述 | 定义与五功能；诺兰模型六阶段；六类分类；生命周期四阶段；建设四原则；开发四方法 | 信息系统 = 人机一体化系统；诺兰模型"计算机时代3+信息时代3" |
| 3.2 业务处理系统（TPS） | 最底层信息系统；数据处理五阶段；是上层系统的"信息产生器" | 服务组织最基础层，为 MIS/DSS 提供原始数据 |
| 3.3 管理信息系统（MIS） | 四大部件（信息源/处理器/用户/管理者）；"层次×职能"矩阵组成 ⚠️ | 功能与组成内容存疑重叠，需核对 |
| 3.4 决策支持系统（DSS） | 半结构化/非结构化决策；三库四库发展史；组成四项 ⚠️（"数据字典"疑应为"数据仓库"） | 面向决策者、辅助而非取代决策 |
| 3.5 专家系统（ES） | 六部件（知识库/综合数据库/推理机/知识获取/解释程序/人机接口）；五大特点 | 六部件结构图是本节核心记忆点 |
| 3.6 办公自动化系统（OAS） | 三大功能（事务处理/信息管理/辅助决策）；组成两种口径 ⚠️ | 概念简单，考试权重低 |
| 3.7 企业资源规划（ERP） | 集成物流/资金流/信息流；11 模块（含 MPS/MRP/CRP 主线）| 本质是管理思想，非单纯信息系统 |
| 3.8 典型信息系统架构模型 | 电子政务 5 模式（G2G/G2B/G2C/C2G/G2E）；电子商务 4 模式（B2B/B2C/C2C/C2B-O2O） | 模式辨析型选择题的常见素材 |

## 重点与难点

1. **重点**：六类信息系统（TPS/MIS/DSS/ES/OAS/ERP）的**定义与组成部件**是选择题辨析的主要来源，建议按"服务对象层级"（TPS 最底层 → ERP 跨部门集成）串记，而非孤立背诵。
2. **难点**：专家系统六部件的相互关系（知识获取→知识库→推理机↔综合数据库→解释程序，人机接口连接用户/专家）容易记混，建议对照本章 3.5 的结构图理解而非死记列表。
3. **待补强**：本章存疑点密度是全书目前最高的一章（详见各小节 ⚠️ 标注），尤其 3.4.4 DSS 组成"数据字典/数据仓库"的疑似笔误、3.7.3 ERP 功能缺失，**强烈建议翻实体书逐条核对**后再进入刷题阶段。
