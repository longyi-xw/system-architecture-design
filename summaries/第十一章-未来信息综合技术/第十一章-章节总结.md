## 本章主线

本章是全书唯一一章**"技术名词科普"性质**的内容——不讲架构方法，只把当下几项前沿技术各介绍一遍，为后续第 14 章（云原生）、第 19 章（大数据）铺垫概念。

六节之间**不是并列的六个孤岛**，而是有一根线：

> **11.1 CPS 是总纲**——它要"物理空间与信息空间闭环"，于是需要
> **11.2 人工智能**（让信息空间会分析决策）+ **11.3 机器人**（让物理侧会执行，机器人 4.0 就是"边缘计算 + 云端分布式智能"）+
> **11.4 边缘计算**（解决数据在哪算）+ **11.5 数字孪生**（给物理实体造数字分身，其"核心技术清单"里同时出现了数字孪生、边缘计算、云计算、大数据）+
> **11.6 云计算与大数据**（底座与燃料）。

**一句话**：**CPS 是骨架，AI 是大脑，机器人是手脚，边缘计算是神经末梢，数字孪生是镜像，云计算和大数据是地基和血液。**

## 重点与难点

### 1. 重点：本章考的几乎全是「名单」

这一章没有推导、没有方法论，**考点就是能不能把名单背全背对**。把下面这些口诀记住，本章基本就拿下了：

| 知识点 | 口诀 |
| --- | --- |
| CPS 本质四动作 | **感知 · 分析 · 决策 · 执行**（闭环） |
| CPS 四大要素 | **硬件撑 · 软件核 · 网络传 · 平台聚** |
| AI 六大关键技术 | **听 · 看 · 记 · 说 · 造 · 学** |
| 机器学习四模式 | **有标签 / 没标签 / 少量标签 / 靠奖惩** |
| 机器人 4.0 五技术 | **协同算 · 持续学 · 有图谱 · 懂场景 · 保安全** |
| 边缘计算四特点 | **连 · 入 · 苛 · 散** |
| 云部署四模式 | **谁都能用 → 一圈人用 → 只有我用 → 拼起来用** |
| 大数据分析五步 | **取 → 洗 → 合 → 算 → 解** |

### 2. 难点：本章的易混对子

| 易混对子 | 分辨方法 |
| --- | --- |
| **CPS 单元级 / 系统级 / SoS 级** | 侧重点不同：**感知控制 → 互联协同 → 数据服务** |
| **程序机器人 / 示教再现机器人 / 智能机器人** | **写给它 / 教给它 / 它自己改** |
| **PaaS / SaaS** | 给的是**运行环境**＝PaaS，给的是**现成软件**＝SaaS |
| **公有云 / 社区云** | 社区云是**若干需求相似的组织**共享，不是面向公众 |
| **建模 / 仿真** | 建模是**把理解写下来**，仿真是**把模型跑起来验证** |
| **云 / 边分工（边云协同）** | 统一规律：**边执行、云策略**；智能协同＝**边推理、云训练** |

### 3. 容易被忽略的三个细节

1. **CPS 四大要素里"一软（工业软件）"才是核心**，不是硬件、不是平台。
2. **大数据分析的最后一步是「解释」**，不是"可视化"也不是"决策"。
3. **边缘计算"联接性是基础"**、**"是数据的第一入口"**——这两句是原文式表述，最适合出判断/填空。
